# Roadmap productivo

Domus tiene el alcance funcional MVP completo. La preparacion productiva se
estima en `85%` y mantiene estas incorporaciones deliberadamente abiertas:

- paginacion estandarizada para listados de alto volumen;
- recuperacion de contrasena mediante un proveedor de correo;
- administracion del catalogo de espacios comunes;
- pruebas de integracion PostgreSQL con Testcontainers dentro de CI;
- cookies `HttpOnly` para refresh tokens en despliegues web;
- observabilidad, alertas y ambientes `staging`/`production`;
- mapas y notificaciones push solo si se confirma el alcance movil.

Estas tareas no deben presentarse como funciones ya implementadas.
